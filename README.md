# Симулятор муравья

## Описание проекта

«Симулятор муравья» — учебное приложение на языке C# с графическим интерфейсом WPF. Программа моделирует перемещение муравья по клеточному игровому полю и изменение цветов клеток по заданным правилам.

## Используемые технологии

- C#
- WPF
- XAML
- Visual Studio 2022

## Возможности программы

- Создание игрового поля с заданным количеством строк и столбцов.
- Настройка скорости симуляции.
- Запуск движения муравья.
- Приостановка симуляции.
- Сброс игрового поля.
- Отображение количества выполненных шагов.
- Проверка допустимых значений настроек.

## Правила движения

1. Если муравей находится на белой клетке, он поворачивает направо, а цвет клетки меняется на чёрный.
2. Если муравей находится на чёрной клетке, он поворачивает налево, а цвет клетки меняется на белый.
3. После поворота муравей перемещается на одну клетку вперёд.

## Управление

- **Сгенерировать** — создать игровое поле с указанными размерами.
- **Запустить** — начать симуляцию.
- **Пауза** — временно остановить движение.
- **Сбросить** — остановить симуляцию и заново создать исходное состояние поля.

## Ограничения настроек

- Количество строк: от 2 до 100.
- Количество столбцов: от 2 до 100.
- Скорость: от 10 до 2000 миллисекунд.

## Запуск проекта

1. Откройте решение проекта в Visual Studio 2022.
2. Соберите решение.
3. Запустите приложение клавишей F5.

Для запуска собранной версии откройте файл `AntSimulator.exe` в папке сборки `bin/Release`. Для переноса приложения на другой компьютер убедитесь, что вместе с исполняемым файлом присутствуют необходимые файлы сборки и установлен подходящий .NET Runtime.
